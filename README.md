# Week 1 – Basic Quantitative Models Using C++

## Internship: YuvaIntern

This project is part of my Week 1 internship task at YuvaIntern.

The project demonstrates the implementation of basic quantitative models using C++.

## Models Implemented

### 1. Simple Interest

Calculates simple interest using:

SI = (P × R × T) / 100

### 2. Compound Interest

Calculates compound interest using:

A = P × (1 + R/100)^T

### 3. Simple Linear Regression

Finds the relationship between two variables using the equation:

Y = a + bX

The program can also predict Y for a given X value.

## Technologies Used

* C++

* Mathematical Operations

## Features

* Menu-driven program
